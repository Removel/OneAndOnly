## 技术实现细节

### SSE 事件格式

```
event: <事件类型>
data: <JSON数据>

```

### 支持的事件类型

| 事件类型 | 用途 | 数据格式 |
|---------|------|---------|
| `token` | 逐字输出 | `{"content": "文本片段"}` |
| `done` | 完成标记 | `{"status": "completed", "emotion_vac": {}, "retry_times": 0}` |
| `error` | 错误信息 | `{"message": "错误描述"}` |

### 核心实现逻辑

```python
async for event in compiled_graph.astream_events(initial_state, config=config, version="v2"):
    event_type = event.get("event", "")
    
    if event_type == "on_chat_model_stream":
        chunk = event.get("data", {}).get("chunk")
        if chunk and hasattr(chunk, "content") and chunk.content:
            yield f"event: token\ndata: {json.dumps({'content': chunk.content})}\n\n"
    
    elif event_type == "on_chain_end":
        final_state = event.get("data", {}).get("output")
```

### 关键技术点

1. **AsyncSqliteSaver**：使用异步 SQLite 检查点，支持异步操作
2. **astream_events()**：捕获 LangGraph 的所有事件，包括 LLM token 流
3. **事件过滤**：只处理 `on_chat_model_stream` 和 `on_chain_end` 事件
4. **异步生成器**：使用 `async for` 和 `yield` 实现真正的流式输出
5. **独立的异步管理器**：`AsyncChatManager` 专门处理流式聊天，不影响同步聊天
