## 问题描述
对话历史框没有拖动功能，导致整个页面被放大，影响用户体验。

## 复现步骤
1. 打开应用主界面
2. 进行多次对话，使对话历史内容增多
3. 尝试拖动对话历史区域边界以调整大小
4. 发现无法拖动，或拖动操作导致整个页面缩放

## 预期行为
- 用户应该能够拖动对话历史框的滚动条来调整能看到的对话历史内容量
- 拖动操作不应该影响页面其他元素的缩放比例

## 实际行为
- 对话历史框无法拖动调整大小
- 拖动操作导致整个页面被放大，影响整体布局

## 原因分析

此问题实际上是"MessageList滚动条不显示"问题的一个表现形式：

1. **容器高度无限扩展**：由于`.app-shell`使用`min-height: 100dvh`而非`height: 100dvh`，整个应用容器可以随内容无限扩展。

2. **页面整体变大**：当对话历史内容增多时，MessageList容器随内容扩展，导致整个页面高度超出视口，看起来像是"页面被放大"。

3. **无法拖动滚动条**：由于容器高度等于内容高度（`offsetHeight === scrollHeight`），滚动条不会出现，用户无法通过拖动滚动条来查看历史内容。

4. **用户体验混淆**：用户期望的"拖动"是指拖动滚动条来浏览内容，但由于滚动条不存在，整个页面变大，用户只能通过浏览器的页面缩放来查看，造成"页面被放大"的错觉。

## 解决方法

通过修复"MessageList滚动条不显示"问题来解决此问题。关键修改：

**文件：frontend/src/views/HomeView.vue**

```css
/* 修改前 */
.app-shell {
  display: flex;
  flex-direction: column;
  min-height: 100dvh;  /* 允许无限扩展 */
  background: var(--color-bg-base);
}

/* 修改后 */
.app-shell {
  display: flex;
  flex-direction: column;
  height: 100dvh;  /* 固定高度 */
  background: var(--color-bg-base);
}
```

**文件：frontend/src/components/chat/MessageList.vue**

```css
.message-list {
  flex: 1;
  min-height: 0;  /* 允许flex子元素收缩 */
  overflow-y: auto;  /* 启用垂直滚动 */
  padding: 16px;
  display: flex;
  flex-direction: column;
}
```

## 变动的代码文件

1. **frontend/src/views/HomeView.vue**
   - `.app-shell`: `min-height: 100dvh` → `height: 100dvh`
   - `.main`: 移除`max-height: 100%`
   - `.chat-area`: 移除`max-height: 100%`

2. **frontend/src/components/layout/ChatPanel.vue**
   - `.chat-panel`: `height: 100%` → `flex: 1`

3. **frontend/src/components/chat/MessageList.vue**
   - `.message-list`: 添加`min-height: 0`和flex布局

## 验证结果
修复后：
- 页面高度固定为视口高度，不再随内容扩展
- MessageList正确显示滚动条
- 用户可以通过拖动滚动条浏览历史对话
- 页面布局稳定，不会出现"被放大"的现象

此问题作为"MessageList滚动条不显示"的衍生问题被一并解决。
