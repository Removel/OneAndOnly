# One and Only 项目计划书

## 一、项目概述

### 1.1 项目名称
One and Only 高人格仿真虚拟陪伴项目

### 1.2 项目愿景
打造一款以对话框交互为核心、Unity为可视化载体的专属虚拟陪伴产品，依托AI Agent技术赋予虚拟人物独立人格、完整记忆、真实情绪及逻辑思维，模拟“灵魂伴侣、至交挚友、至亲亲人”的深度陪伴感，实现“可对话、有灵魂、看得见、可互动”的专属虚拟对象体验，同时作为大四毕业设计，提前布局开发，确保毕业时完成高质量技术落地与成果展示（当前为大二下，预留充足开发与打磨时间）。

### 1.3 项目核心目标
- **技术目标**：完成大文本AI蒸馏、外挂Embedding小模型风格切换、LangGraph Agent架构开发、Unity可视化联动四大核心技术落地，实现全链路流畅运行，同步提升自身AI与开发技术能力，适配学业进阶需求。
- **产品目标**：开发出可正常交互的完整Demo，支持对话框文字交流、虚拟人物表情/动作联动、人格风格切换、长记忆留存，达到高仿真人性模拟效果，作为个人作品集核心项目。
- **毕业目标**：按时完成项目开发，形成完整的项目文档、代码成果及演示视频，满足毕业设计要求，凭借该项目提升就业或升学竞争力。

### 1.4 项目范围
本项目聚焦于核心功能落地，结合大二至大四的学业节奏，不追求复杂UI设计及多平台适配，重点完成“AI逻辑层+可视化层”的闭环，分阶段推进、逐步优化，具体范围如下：
- **核心功能**：大文本解析与蒸馏、人格风格切换、Agent对话与决策、Unity虚拟人物动作/表情联动、长记忆留存。
- **技术边界**：不涉及复杂的3D模型建模（采用开源模型适配）、不开发移动端/网页端（仅本地PC端运行）、不做高并发优化（满足个人使用即可），优先适配学业之余的开发节奏。
- **可选功能**：Unity场景简单搭建、情绪精细化适配，根据学业松紧度和开发进度灵活调整，不影响核心任务推进。

## 二、项目团队与资源

### 2.1 项目团队
**核心成员**：本人（负责全流程技术开发、需求梳理、进度管控），无需额外团队，适配个人毕业设计场景；当前为大二，可利用课余时间积累技术，根据需求咨询导师或学长学姐提供技术建议，同步提升自身能力。

### 2.2 技术资源
- **开发语言**：Python（后端AI、Agent开发）、C#（Unity脚本开发），可利用大二至大三的课余时间逐步熟练掌握。
- **核心框架/工具**：LangGraph（Agent架构）、FastAPI/Flask（接口开发）、Unity（可视化开发）、Embedding小模型（开源模型适配）、大文本AI分析工具（依托现有科研资源或课余自学积累）。
- **开源资源**：Unity开源人形模型、动画资源、表情BlendShape素材，开源Embedding模型（如Sentence-BERT），LangGraph官方文档及案例，降低开发难度，适配课余开发节奏。
- **硬件资源**：个人PC（满足Unity运行、AI模型本地部署需求，无需额外服务器），可根据开发需求逐步优化设备配置。

### 2.3 参考资源
LangGraph官方教程、Unity接口开发文档、AI Agent人格模拟相关案例、大文本蒸馏科研资料，可咨询学校导师、学长学姐获取技术指导，同时利用在线课程（如B站、Coursera）补充技术短板，贴合大二至大三的学习节奏。

## 三、核心技术方案

### 3.1 技术架构总览
整体采用**四层架构**，实现解耦开发，便于分阶段落地和后期优化，适配大二至大四的渐进式开发节奏，架构流程如下：

**用户交互层（对话框） → AI核心层（大文本蒸馏+Embedding风格+LangGraph Agent） → 通信接口层 → 可视化层（Unity）**

### 3.2 各层技术细节

#### 3.2.1 大文本AI分析与蒸馏层
- **核心任务**：解析超长文本（如人设背景、对话历史、用户需求），萃取核心逻辑，为Agent提供记忆和人设支撑。
- **技术实现**：依托课余自学或科研实践（2026-04-20至2026-06-10，对应大三下），完成文本解析、总结、核心方案蒸馏算法开发，输出结构化的文本信息，供后续Agent调用，同步结合课程学习积累相关技术。

#### 3.2.2 外挂Embedding小模型风格层
- **核心任务**：实现虚拟人物语气、文风、性格风格的快速切换，适配“灵魂伴侣、挚友、亲人”等不同陪伴场景。
- **技术实现**：接入开源Embedding小模型，将风格参数（如温柔、活泼、沉稳）转化为向量特征，与Agent对话输出结合，实现风格动态切换，开发周期为大文本蒸馏完成后4个月（对应大三下至大四上），利用课余时间逐步推进。

#### 3.2.3 LangGraph Agent心智层
- **核心任务**：搭建虚拟人物的思维逻辑、记忆链、情绪决策系统，实现高仿真人性模拟，避免模板化回复。
- **技术实现**：基于LangGraph框架设计多Agent架构，开发记忆存储、推理决策、情绪判断模块，接收用户对话和大文本蒸馏结果，输出自然语言回复和结构化行为指令（情绪、动作编号），开发周期为风格层完成后3个月（对应大四上），利用假期和课余时间集中开发。

#### 3.2.4 通信接口层
- **核心任务**：实现AI核心层与Unity可视化层的双向通信，传递对话信息和行为指令。
- **技术实现**：采用HTTP接口（入门简单、适配个人开发），用FastAPI搭建后端接口，Unity端用C#编写请求/接收脚本，解析Agent输出的JSON格式指令（包含回复内容、情绪、动作），确保通信流畅、低延迟，可在学习对应语言和框架后逐步实现。

#### 3.2.5 Unity可视化层
- **核心任务**：将Agent的行为指令转化为虚拟人物的表情、动作，实现可视化交互。
- **技术实现**：选用开源人形模型（Humanoid标准骨架），搭建动画状态机（预设idle、倾听、开心、难过等基础动作），用BlendShape实现表情控制，通过C#脚本接收接口指令，自动切换动画和表情，完成联动适配，可利用课余时间自学Unity基础，逐步推进开发。

## 四、项目进度规划（适配大二下启动，大四毕业交付）

当前为大二下（假设时间为2026年3月），大四毕业时间为2028年6月，结合学业节奏（课程学习、考试、假期），分7个阶段推进，放缓前期节奏、预留充足缓冲，明确每个阶段的任务、产出物和时间节点，确保不影响学业的同时，按时完成项目交付。

- **产出物**：技术学习计划、开源资源整理清单、基础环境搭建（Python、Unity）。
