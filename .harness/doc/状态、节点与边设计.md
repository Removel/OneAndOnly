# One and Only 项目 · LangGraph 架构总结（最终版）

## 1. 核心思路
- 去掉人格参数、去掉 Embedding 风格向量，改用 **LoRA 微调模型** 控制语言风格。
- 情绪用 **Valence/Arousal/Control（VAC三维）** 表示。
- Live2D 动作：**VAC → 自训练小模型 → 动作参数**。
- 流程改为：**Plan → Execute → Evaluate**（执行后再评估）。
- 支持后续扩展 **Skills/工具调用**，不改动主链路。

---

## 2. 共享状态（State）
```
GraphState:
  user_input、memory、thought、
  need_skill、skill_name（先不实现）、skill_result（先不实现）、tools
  response_text、emotion_vac、action_params、
  evaluate_result、**need_evaluate（新增：是否需要评估）**
```

---

## 3. 节点设计（共7个）
1. **MemoryRetrieve**：检索相关历史对话
2. **Plan**：理解意图、生成思考、决定是否调用技能
3. **Execute**：
   - 生成回复文本
4. **Evaluator**：评估文本、情绪、动作是否合理
5. **FinalOutput**：输出最终结果
   - 调整文本风格
   - 输出情绪参数
   - 异步总结当前对话
   
---

---

## 5. 智能体分工(注：虽然是智能体但是有些智能体只会用到对话服务，因此在util当中有些是通过llm创建有些通过agent创建)
- **Planner**：思考、定方向、决策是否用技能
- **Executor**：生成文本、VAC、Live2D动作（LoRA+小模型）
- **Evaluator**：评估一致性，不合理则回退重规划
- **MemoryManager**：查找记忆、提取相关信息
- **Summarizer**：总结当前对话、提取关键信息
---

## 6. 扩展原则（加技能/工具）
- **主链路不变**：Plan → Execute → Evaluator
- **新增节点插在 Planner 后、Executor 前**
