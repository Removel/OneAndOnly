# 流式聊天功能文档

## 概述

本项目现在支持流式聊天功能，通过 Server-Sent Events (SSE) 协议实时返回 AI 的回复内容。

## API 端点

### POST `/api/chat-stream`

流式聊天端点，返回 SSE 事件流。

**请求体:**
```json
{
  "human_input": "用户输入内容",
  "session_id": 1,
  "clear_history": false
}
```

**参数说明:**
- `human_input` (string, 必需): 用户输入的文本内容
- `session_id` (integer, 必需): 会话ID，用于维护对话历史
- `clear_history` (boolean, 可选): 是否清空历史记录，默认为 false

**响应格式:**

响应采用 SSE (Server-Sent Events) 格式，包含以下事件类型：

#### 1. `token` 事件
逐字输出事件，包含 AI 生成的文本片段。

```
event: token
data: {"content": "文本片段"}

```

#### 2. `done` 事件
完成事件，表示对话已完成。

```
event: done
data: {
  "status": "completed",
  "emotion_vac": {"valence": 0.5, "arousal": 0.3, "control": 0.7},
  "retry_times": 0
}

```

#### 3. `error` 事件
错误事件，表示处理过程中出现错误。

```
event: error
data: {"message": "错误描述"}

```

## 使用示例

### Python 示例

#### 基础示例
```python
import requests
import json

url = "http://localhost:8000/api/chat-stream"

payload = {
    "human_input": "你好，请介绍一下你自己",
    "session_id": 1,
    "clear_history": True
}

response = requests.post(url, json=payload, stream=True)

if response.status_code == 200:
    full_content = ""
    
    for line in response.iter_lines():
        if line:
            decoded_line = line.decode('utf-8')
            
            if decoded_line.startswith('event:'):
                event_type = decoded_line[6:].strip()
            
            elif decoded_line.startswith('data:'):
                data_str = decoded_line[5:].strip()
                if data_str:
                    data = json.loads(data_str)
                    
                    if 'content' in data:
                        full_content += data['content']
                        print(data['content'], end='', flush=True)
                    
                    elif event_type == 'done':
                        print(f"\n完成！情绪: {data.get('emotion_vac', {})}")
                    
                    elif event_type == 'error':
                        print(f"\n错误: {data.get('message', '未知错误')}")
```

#### 高级示例
```python
import requests
import json

def stream_chat_with_retry(human_input, session_id, max_retries=3):
    url = "http://localhost:8000/api/chat-stream"
    
    for attempt in range(max_retries):
        try:
            payload = {
                "human_input": human_input,
                "session_id": session_id,
                "clear_history": False
            }
            
            response = requests.post(
                url,
                json=payload,
                stream=True,
                timeout=30,
                headers={
                    "Accept": "text/event-stream",
                    "Cache-Control": "no-cache"
                }
            )
            
            if response.status_code == 200:
                full_content = ""
                emotion_vac = {}
                
                for line in response.iter_lines():
                    if line:
                        decoded_line = line.decode('utf-8')
                        
                        if decoded_line.startswith('event:'):
                            event_type = decoded_line[6:].strip()
                        
                        elif decoded_line.startswith('data:'):
                            data_str = decoded_line[5:].strip()
                            if data_str:
                                data = json.loads(data_str)
                                
                                if event_type == 'token' and 'content' in data:
                                    full_content += data['content']
                                    print(data['content'], end='', flush=True)
                                
                                elif event_type == 'done':
                                    emotion_vac = data.get('emotion_vac', {})
                                    print(f"\n完成！")
                                    return full_content, emotion_vac
                
                return full_content, emotion_vac
            
            else:
                print(f"请求失败: {response.status_code}")
                if attempt < max_retries - 1:
                    print(f"重试中... ({attempt + 1}/{max_retries})")
                    import time
                    time.sleep(2)
        
        except requests.exceptions.Timeout:
            print(f"请求超时，重试中... ({attempt + 1}/{max_retries})")
            if attempt < max_retries - 1:
                import time
                time.sleep(2)
        
        except Exception as e:
            print(f"发生错误: {str(e)}")
            if attempt < max_retries - 1:
                import time
                time.sleep(2)
    
    return None, None

# 使用示例
content, emotion = stream_chat_with_retry("你好", 1)
if content:
    print(f"\n情绪分析: {emotion}")
```

### JavaScript/TypeScript 示例

```javascript
async function streamChat(humanInput, sessionId) {
  const response = await fetch('http://localhost:8000/api/chat-stream', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'text/event-stream',
    },
    body: JSON.stringify({
      human_input: humanInput,
      session_id: sessionId,
      clear_history: false
    })
  });

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let fullContent = '';
  let currentEventType = '';

  while (true) {
    const { done, value } = await reader.read();
    
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('event:')) {
        currentEventType = line.slice(6).trim();
      } else if (line.startsWith('data:')) {
        const dataStr = line.slice(5).trim();
        if (dataStr) {
          try {
            const data = JSON.parse(dataStr);

            if (currentEventType === 'token' && data.content) {
              fullContent += data.content;
              process.stdout.write(data.content);
            } else if (currentEventType === 'done') {
              console.log('\n完成！');
              console.log('情绪VAC:', data.emotion_vac);
            } else if (currentEventType === 'error') {
              console.error('\n错误:', data.message);
            }
          } catch (e) {
            console.error('解析数据失败:', e);
          }
        }
      }
    }
  }

  return fullContent;
}

// 使用示例
streamChat('你好，请介绍一下你自己', 1)
  .then(content => console.log('\n完整内容:', content))
  .catch(error => console.error('错误:', error));
```

## 事件流处理建议

### 1. 连接管理
- 设置合理的超时时间
- 实现重试机制
- 处理网络中断情况

### 2. 内容处理
- 实时显示 token 内容，提供打字机效果
- 缓存完整内容用于后续处理
- 处理特殊字符和格式

### 3. 错误处理
- 监听 `error` 事件
- 捕获网络异常
- 提供用户友好的错误提示

### 4. 性能优化
- 使用流式处理，避免内存溢出
- 限制单次响应的最大长度
- 实现内容截断和分页

## 与原有 API 的区别

| 特性 | `/api/chat` | `/api/chat-stream` |
|------|-------------|-------------------|
| 响应方式 | 一次性返回完整响应 | 流式返回，逐字输出 |
| 响应格式 | JSON | SSE (Server-Sent Events) |
| 用户体验 | 需要等待完整响应 | 实时看到生成过程 |
| 适用场景 | 简单查询、后台任务 | 交互式对话、长文本生成 |

## 注意事项

1. **会话管理**: 流式聊天和非流式聊天共享相同的会话ID，可以混合使用
2. **历史记录**: `clear_history` 参数控制是否清空历史，建议首次对话时设置为 `true`
3. **超时设置**: 建议设置合理的超时时间，避免长时间等待
4. **错误处理**: 务必实现错误处理逻辑，捕获 `error` 事件
5. **资源清理**: 使用完毕后及时关闭连接，释放资源

## 故障排查

### 问题：无法连接到服务器
- 检查后端服务是否已启动
- 确认端口号是否正确
- 检查防火墙设置

### 问题：没有收到任何事件
- 检查请求格式是否正确
- 确认 `Accept` 头是否设置为 `text/event-stream`
- 查看服务器日志

### 问题：收到错误事件
- 检查 `error_message` 字段获取具体错误信息
- 确认输入参数是否有效
- 查看服务器日志获取详细错误

### 问题：流式输出不流畅
- 检查网络连接质量
- 确认服务器性能是否足够
- 考虑调整缓冲区大小
