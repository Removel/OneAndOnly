## 问题描述
对话操作栏当中的按钮排序比较混乱，外观上不规整。其次文字位置在按钮当中并不处于居中位置，外观上也不美观。

## 复现步骤
1. 打开应用主界面
2. 选择一个对话
3. 观察对话操作栏中的按钮排序及文字位置，发现问题

## 预期行为
- 按钮排序应当美观，文字位置应当居中。
- 会话、会话状态应当在左上位置
- 新建对话、清空记录、导出按钮应当在会话、会话状态的下方，并且该三个按钮应当等宽等高，等距分布。

## 实际行为
- 按钮排序比较混乱，文字位置在按钮当中并不处于居中位置，外观上也不美观。

## 原因分析

1. **布局结构不清晰**：原始实现中按钮排列方式不够规整，没有使用统一的布局系统。

2. **文字对齐问题**：按钮内部的图标和文字没有正确居中对齐，导致视觉上不协调。

3. **按钮宽度不一致**：三个操作按钮（新建对话、清空记录、导出）宽度不统一，视觉上不整齐。

## 解决方法

**文件：frontend/src/components/chat/ChatActionBar.vue**

### 1. 使用Grid布局实现等宽等距分布
```vue
<template>
  <div class="action-bar">
    <div class="top-row">
      <span class="label">{{ current ? `会话 #${current.id}` : '尚未选择会话' }}</span>
      <span v-if="current" class="status-pill">{{ current.status }}</span>
    </div>
    <div class="button-row">
      <!-- 三个按钮 -->
    </div>
  </div>
</template>
```

### 2. CSS布局优化
```css
.action-bar {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 12px 16px;
  background: var(--color-bg-card);
  border-bottom: 1px solid var(--color-border-light);
}

.top-row {
  display: flex;
  align-items: center;
  gap: 10px;
  color: var(--color-text-primary);
  font-weight: 500;
  min-width: 0;
}

.button-row {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 三列等宽 */
  gap: 8px;  /* 等距分布 */
}

.action-btn {
  width: 100%;
  text-align: center;
}

/* 确保按钮内容居中 */
.action-btn :deep(.n-button__content) {
  width: 100%;
  display: flex;
  align-items: center;
  justify-content: center;
  gap: 4px;
  line-height: 1;
}

.action-btn :deep(.n-button__icon) {
  margin: 0 !important;
  display: flex;
  align-items: center;
}
```

### 3. 布局结构
- **顶部行**：会话信息和状态标签，使用flex布局水平排列
- **按钮行**：三个操作按钮使用grid布局，`repeat(3, 1fr)`确保等宽，`gap: 8px`确保等距

### 4. 文字居中
- 使用`:deep()`选择器覆盖NaiveUI按钮的默认样式
- 设置`display: flex; align-items: center; justify-content: center`确保图标和文字垂直水平居中
- 移除默认的margin，使用`gap: 4px`控制图标和文字间距

## 变动的代码文件

1. **frontend/src/components/chat/ChatActionBar.vue**
   - 重构整体布局结构，分为top-row和button-row
   - 使用grid布局实现三个按钮等宽等距
   - 添加深度选择器优化按钮内容对齐
   - 优化间距和padding

## 验证结果
修复后按钮排列整齐，三个操作按钮等宽等高等距分布，文字和图标在按钮中完美居中，视觉效果规整美观。
