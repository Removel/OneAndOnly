## 问题描述
在没有对话消息时，空状态提示（"暂无消息"）不能占满整个消息列表区域，而是只显示在顶部一小块区域。

## 复现步骤
1. 打开应用主界面（无历史消息）
2. 观察右侧聊天面板的消息列表区域
3. 空状态提示只显示在顶部，下方有大片空白

## 预期行为
- 空状态提示应该垂直居中显示在整个消息列表区域
- 空状态容器应该占满整个可用空间

## 实际行为
- 空状态提示挤在顶部
- 大部分消息列表区域是空白
- 视觉上不协调

## 环境信息
- 操作系统: Windows 11
- 浏览器: Chrome
- 前端框架: Vue 3 + Vite

---

## 原因分析

问题根源在于`.empty`容器的高度设置方式：

1. **使用height: 100%的问题**：`.empty`使用`height: 100%`，但其父元素`.message-list`在修复滚动条问题前不是一个明确的flex容器，导致百分比高度无法正确计算。

2. **Flex布局的正确方式**：在flex容器中，子元素应该使用`flex: 1`来占满剩余空间，而不是`height: 100%`。

3. **min-height: 0的必要性**：在flex容器中，需要显式设置`min-height: 0`来允许子元素正确收缩和扩展。

## 解决方法

**文件：frontend/src/components/chat/MessageList.vue**

### 1. 确保父容器是flex布局
```css
.message-list {
  flex: 1;
  min-height: 0;
  overflow-y: auto;
  padding: 16px;
  display: flex;           /* 添加 */
  flex-direction: column;  /* 添加 */
}
```

### 2. 修改空状态容器使用flex
```css
/* 修改前 */
.empty {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  height: 100%;  /* 在非明确flex父容器中不生效 */
  color: var(--color-text-tertiary);
  font-size: 14px;
  gap: 12px;
}

/* 修改后 */
.empty {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  flex: 1;        /* 占满剩余空间 */
  min-height: 0;  /* 允许正确收缩 */
  color: var(--color-text-tertiary);
  font-size: 14px;
  gap: 12px;
}
```

## 变动的代码文件

1. **frontend/src/components/chat/MessageList.vue**
   - `.message-list`: 添加`display: flex; flex-direction: column`
   - `.empty`: `height: 100%` → `flex: 1; min-height: 0`

## 验证结果
修复后空状态提示正确居中显示在整个消息列表区域，用户反馈："现在可以了"。
